# Vim Quest — Le donjon du code

Un jeu solo en français pour apprendre Vim et Neovim. La campagne contient 33 étages : déplacements et comptes, insertion et nouvelles lignes, suppressions, changements, copier/coller, annulation, recherche, sélections, objets texte, navigation dans le code, indentation, substitution, macros, fichiers et buffers.

## Jouer

Ouvre `index.html` dans ton navigateur. Les premières salles te font explorer un labyrinthe ; dans l’atelier, saisis la commande demandée pour déverrouiller la sortie, puis traverse la salle avec h, j, k et l. Tu peux aussi utiliser directement les touches de déplacement.

La progression est stockée localement dans le navigateur. Le bouton « Recommencer » remet la campagne à zéro.
