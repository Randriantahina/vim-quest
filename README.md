# Vim Quest — Le donjon du code

Un jeu de labyrinthe solo pour apprendre les commandes de déplacement de Vim et Neovim. Le personnage se contrôle avec les commandes Vim, les étages ajoutent de nouvelles mécaniques et la campagne se sauvegarde dans le navigateur.

## Jouer

Ouvre `index.html` dans ton navigateur. Tape une commande dans la barre en bas et appuie sur Entrée. Tu peux aussi utiliser directement les touches de déplacement.

La progression est stockée localement dans le navigateur. Le bouton « Recommencer » remet la campagne à zéro.
